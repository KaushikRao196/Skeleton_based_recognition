# Skeleton Based Recognition

## Project Overview
This project focuses on implementing skeleton-based recognition algorithms to analyze human movement and gestures. By using skeleton data, we can achieve highly accurate recognition of various activities and poses, making it suitable for applications in healthcare, sports analytics, human-computer interaction, and more.

## Features
- Accurate skeleton tracking using state-of-the-art algorithms.
- Comprehensive dataset for training and validation.
- Real-time recognition capabilities.
- User-friendly interface for easy interaction.

## Installation
To install the project, follow these instructions:
1. Clone the repository:
   ```bash
   git clone https://github.com/KaushikRao196/Skeleton_based_recognition.git
   cd Skeleton_based_recognition
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
After installation, you can run the recognition algorithms using:
```bash
python main.py
```
For more detailed usage instructions, refer to the documentation.
